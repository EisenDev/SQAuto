# Data Reconciliation Automation Tool

## Project Purpose
An internal data operations tool designed to upload, parse, compare, classify, and safely generate batch SQL updates from an Excel sheet and contextual SQL dumps. Its entire operation is offline, deterministic, and template-based to provide safe "dry-run" capabilities before any manual production execution.

## Monorepo Structure
- `docs/` - System architecture, plans, and technical specifications.
- `frontend/` - Next.js internal UI (Dark mode optimized, operations focused).
- `backend/` - FastAPI Python service driving pandas comparison and Jinja2 SQL generation.
- `database/` - Ephemeral Postgres environments for reliable data restoration and querying.
- `mock_data/` - Static files to act as dummy data sets for testing logic.
- `scripts/` - Utilities for quick dev environments and testing.

## Current Status: **Phase 7 Complete — Version 1.0 Stable & Integrated**

### Current Capabilities (V1)
- **Safe Ingestion**: Upload Excel reports and PostgreSQL dumps.
- **Automated Restore**: Automatic schema restoration to ephemeral PostgreSQL environment.
- **Deterministic Reconciliation**: Pandas-driven comparison (Match, Mismatch, Duplicate, Missing).
- **Dynamic Configuration**: User-defined table names, status hooks, and match keys.
- **Transactional SQL Patches**: Jinja2-generated SQL with `ROLLBACK` safety by default.
- **Modern UI**: Dark/Light mode, real-time results summary, and SQL preview.
